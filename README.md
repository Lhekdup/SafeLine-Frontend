# SafeLine - Frontend Client

A secure, offline-first Android messaging application built with a decoupled modular architecture. This repository contains the client-side code for the SafeLine platform, focusing on real-time communication and secure local data persistence.

## Key Features
* **Real-Time Messaging:** Bidirectional communication implemented via WebSocket integration for instant message delivery.
* **Offline-First Architecture:** Ensures the application remains fully functional without an active network connection, syncing seamlessly when connectivity is restored.
* **Secure Local Storage:** End-to-end local data security utilizing Room database encryption to protect sensitive message history on the device.
* **Modular Design:** Built with a decoupled architecture to ensure highly maintainable, scalable, and testable code.
